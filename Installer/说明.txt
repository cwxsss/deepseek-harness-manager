DeepSeek Harness 单文件安装器

使用方式：
1. 将“DeepSeek Harness 控制台.exe”复制到目标 Windows 电脑。
2. 双击该 EXE，点击“安装 DeepSeek”。
3. 等待提示“安装完成”，然后继续使用管理器中的启动、关闭、更新和卸载功能。

说明：
- 该 EXE 为 Windows x64 自包含单文件，已内置安装脚本、启动/关闭/更新脚本及两个本地 SSS 插件包。
- `payload`、`.cmd`、`.ps1` 和 `.tgz` 文件仅用于开发、备份或批量分发，普通用户不需要单独接收。
- 首次安装需要联网下载官方 Harness 与官方 Web UI；首次启动后访问地址为 http://127.0.0.1:3080/。
- 如果目标电脑没有 Node.js，安装程序会下载官方 Node.js 运行时。
- 为保护已有内容，检测到目标电脑存在 DeepSeekHarness 或 .dsh\profiles 时会停止，不会覆盖。
- 桌面仅创建“DeepSeek Harness 控制台.exe”；启动、关闭和更新均在控制台中完成。
